## 🔄 Request → Response Flow (3 Layers)

```
REQUEST: /api/products/123
   ↓
PRESENTATION (Controller)
   • Validate input
   • Call service
   ↓
BUSINESS LOGIC (Service)
   • Apply business rules
   • Call repository
   ↓
DATA ACCESS (Repository)
   • Query database
   • Return entity
   ↓
RESPONSE: JSON with ApiResponse wrapper
```

## 📊 Layer Responsibilities

### 1. Presentation Layer (Controllers)
- **File Pattern**: `{Module}Controller.java`
- **Responsibility**: HTTP routing, validation, response formatting
- **Annotations**: `@RestController`, `@GetMapping`, `@PostMapping`
- **Response Format**: All wrapped in `ApiResponse<T>`
- **Location**: `controller/` folders
- **Status Codes**: 200 (OK), 201 (Created), 400 (Bad Request), 404 (Not Found), 500 (Server Error)

### 2. Business Logic Layer (Services)
- **File Pattern**: `{Module}Service.java` (interface) + `{Module}ServiceImpl.java` (impl)
- **Responsibility**: Validate, transform, calculate, orchestrate
- **Annotations**: `@Service`, `@Transactional`
- **Key Features**: 
  - Transactions (@Transactional)
  - Validation logic
  - Complex calculations
  - Inventory updates
  - Auto-deduction/addition
- **Location**: `service/` folders
- **Important**: All business logic lives here, NOT in controller

### 3. Data Access Layer (Repositories)
- **File Pattern**: `{Module}Repository.java` extends `JpaRepository<T, ID>`
- **Responsibility**: Database operations
- **Framework**: Spring Data JPA
- **Methods**:
  - Auto CRUD: `save()`, `delete()`, `findById()`, `findAll()`
  - Custom: `@Query` for complex searches
  - Native: `@Query(nativeQuery=true)` for SQL
- **Location**: `repository/` folders
- **Transaction**: Automatic @Transactional on repository methods

### 4. Database Layer (MySQL)
- **Location**: `localhost:3306/retail_management_system`
- **Version**: MySQL 8.0
- **DDL**: Auto-generated by Hibernate (`ddl-auto=update`)
- **Relationships**: Foreign keys, constraints, indexes
- **Access**: Via Spring Data JPA repositories

## 🔌 Common Annotations Reference

### Spring Boot
```java
@SpringBootApplication      // Main class
@EnableWebMvc              // Enable web support
@Configuration             // Configuration class
@Bean                      // Create managed bean
```

### Controllers
```java
@RestController            // REST endpoint class
@RequestMapping("/api")    // Base path
@GetMapping("/path")       // GET endpoint
@PostMapping("/path")      // POST endpoint
@PutMapping("/path/{id}")  // PUT endpoint
@DeleteMapping("/path/{id}") // DELETE endpoint
@PathVariable Long id      // URL parameter
@RequestParam String name  // Query parameter
@RequestBody DTO dto       // Request body
@Valid                     // Validate DTO
```

### Services
```java
@Service                   // Service class
@Transactional            // Transaction boundary
@Transactional(readOnly=true)  // Read-only transaction
@Async                    // Async execution
@Cacheable("cache-name")  // Cache result
```

### JPA/Repository
```java
@Entity                   // Database entity
@Table(name="table_name") // Table mapping
@Id                      // Primary key
@GeneratedValue(strategy=IDENTITY) // Auto-increment
@Column(nullable=false)  // Column constraint
@ManyToOne               // Many-to-One relationship
@OneToMany               // One-to-Many relationship
@JoinColumn(name="fk")   // Foreign key column
@Query("...")            // Custom query
```

### Exception Handling
```java
@ControllerAdvice        // Global exception handler
@ExceptionHandler(SomeException.class)  // Handle specific exception
@ResponseStatus(NOT_FOUND) // HTTP status code
```

### Validation
```java
@NotNull                 // Not null constraint
@NotBlank                // Not blank constraint
@Size(min=1, max=100)   // Size constraint
@Email                   // Email format validation
@Pattern(regexp="...")   // Regex validation
```

## 📝 Creating New REST Endpoint - Quick Steps

### Step 1: Create DTOs (if needed)
```java
// src/main/java/com/retailbus/module/dto/ModuleRequest.java
public class ModuleRequest {
    @NotNull
    private String name;
    // ... fields
}

// src/main/java/com/retailbus/module/dto/ModuleResponse.java
public class ModuleResponse {
    private Long id;
    private String name;
    // ... fields
}
```

### Step 2: Create/Update Entity
```java
// src/main/java/com/retailbus/module/entity/Module.java
@Entity
@Table(name="modules")
public class Module {
    @Id @GeneratedValue(strategy=IDENTITY)
    private Long id;
    
    @Column(nullable=false)
    private String name;
    // ... fields
}
```

### Step 3: Create Repository
```java
// src/main/java/com/retailbus/module/repository/ModuleRepository.java
public interface ModuleRepository extends JpaRepository<Module, Long> {
    @Query("SELECT m FROM Module m WHERE m.name = ?1")
    List<Module> findByName(String name);
}
```

### Step 4: Create Service Interface
```java
// src/main/java/com/retailbus/module/service/ModuleService.java
public interface ModuleService {
    ModuleResponse create(ModuleRequest request);
    ModuleResponse getById(Long id);
    List<ModuleResponse> getAll();
    ModuleResponse update(Long id, ModuleRequest request);
    void delete(Long id);
}
```

### Step 5: Implement Service
```java
// src/main/java/com/retailbus/module/service/ModuleServiceImpl.java
@Service
@Transactional
public class ModuleServiceImpl implements ModuleService {
    
    @Autowired
    private ModuleRepository repository;
    
    @Autowired
    private ModuleMapper mapper;
    
    @Override
    public ModuleResponse create(ModuleRequest request) {
        // Validate, transform, save
        Module entity = mapper.toEntity(request);
        Module saved = repository.save(entity);
        return mapper.toResponse(saved);
    }
    // ... other methods
}
```

### Step 6: Create Mapper
```java
// src/main/java/com/retailbus/module/mapper/ModuleMapper.java
@Component
public class ModuleMapper {
    public Module toEntity(ModuleRequest dto) {
        // Convert DTO to Entity
        return new Module(dto.getName());
    }
    
    public ModuleResponse toResponse(Module entity) {
        // Convert Entity to DTO
        return new ModuleResponse(entity.getId(), entity.getName());
    }
}
```

### Step 7: Create Controller
```java
// src/main/java/com/retailbus/module/controller/ModuleController.java
@RestController
@RequestMapping("/api/modules")
public class ModuleController {
    
    @Autowired
    private ModuleService service;
    
    @PostMapping
    public ResponseEntity<ApiResponse<ModuleResponse>> create(@Valid @RequestBody ModuleRequest request) {
        ModuleResponse response = service.create(request);
        return ResponseEntity.status(CREATED)
            .body(ApiResponse.<ModuleResponse>builder()
                .success(true)
                .message("Module created")
                .data(response)
                .timestamp(System.currentTimeMillis())
                .build());
    }
    
    @GetMapping("/{id}")
    public ResponseEntity<ApiResponse<ModuleResponse>> getById(@PathVariable Long id) {
        ModuleResponse response = service.getById(id);
        return ResponseEntity.ok(ApiResponse.<ModuleResponse>builder()
            .success(true)
            .message("Module retrieved")
            .data(response)
            .timestamp(System.currentTimeMillis())
            .build());
    }
    // ... other endpoints
}
```

## 🗄️ Database Table Quick Reference

### Products
```sql
CREATE TABLE products (
  product_id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(255) NOT NULL,
  category VARCHAR(100),
  price DECIMAL(10,2),
  current_stock INT,
  reorder_level INT,
  created_at TIMESTAMP
);
```

### Suppliers
```sql
CREATE TABLE suppliers (
  supplier_id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(255) NOT NULL,
  contact VARCHAR(100),
  city VARCHAR(100),
  active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP
);
```

### Sales
```sql
CREATE TABLE sales (
  sale_id BIGINT PRIMARY KEY AUTO_INCREMENT,
  receipt_num VARCHAR(50) UNIQUE,
  sale_date DATETIME,
  customer_id BIGINT,
  total_amount DECIMAL(12,2),
  tax_amount DECIMAL(10,2),
  discount DECIMAL(10,2),
  status VARCHAR(20),
  FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);
```

### Inventory History
```sql
CREATE TABLE inventory_history (
  history_id BIGINT PRIMARY KEY AUTO_INCREMENT,
  product_id BIGINT NOT NULL,
  qty_change INT,
  type VARCHAR(50),
  reference_id VARCHAR(100),
  created_at TIMESTAMP,
  FOREIGN KEY (product_id) REFERENCES products(product_id),
  INDEX idx_product_date (product_id, created_at)
);
```

## 🔐 Exception Handling Pattern

### Custom Exception
```java
public class ProductNotFoundException extends RuntimeException {
    public ProductNotFoundException(Long id) {
        super("Product not found with ID: " + id);
    }
}
```

### Global Exception Handler
```java
@ControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(ProductNotFoundException.class)
    @ResponseStatus(NOT_FOUND)
    public ResponseEntity<ApiResponse<Void>> handleNotFound(ProductNotFoundException e) {
        return ResponseEntity.status(NOT_FOUND)
            .body(ApiResponse.<Void>builder()
                .success(false)
                .message(e.getMessage())
                .timestamp(System.currentTimeMillis())
                .build());
    }
}
```

### Throwing Exception in Service
```java
@Override
public ProductResponse getById(Long id) {
    Product product = repository.findById(id)
        .orElseThrow(() -> new ProductNotFoundException(id));
    return mapper.toResponse(product);
}
```

## 💡 Design Principles Used

✅ **SOLID Principles**
- Single Responsibility: Each class has one reason to change
- Open/Closed: Open for extension, closed for modification
- Liskov Substitution: Service interface & impl pattern
- Interface Segregation: Focused interfaces
- Dependency Inversion: Inject dependencies

✅ **Design Patterns**
- MVC (Model-View-Controller)
- Repository Pattern (Data access abstraction)
- Service Layer Pattern (Business logic centralization)
- Mapper Pattern (Data transformation)
- Singleton (Spring beans)
- Factory Pattern (Spring @Bean)

✅ **Clean Code**
- Meaningful names
- Small focused methods
- Proper separation of concerns
- No code duplication
- Comprehensive logging
